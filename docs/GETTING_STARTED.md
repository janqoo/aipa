## 🚀 Quick Start

1. **Navigate to the project**:
   ```bash
   cd ai-perfume-recommendation-system
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   ```
   http://localhost:5173
   ```
